# NEXUS Ultimate

A Geometry Dash 2.2081 performance toolkit focused on reducing unnecessary rendering work while preserving gameplay simulation. Windows x64 / Geode 5.11.2.

Features include rendering fast paths, batch filtering, particle controls, frame pacing, optional GPU queue draining and performance diagnostics. Performance varies by level and hardware; consult counters to confirm work skipped. Physics and the game's input code are not modified.
